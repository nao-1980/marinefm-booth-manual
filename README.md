## イベント版の追加機能（Googleスプレッドシート連携）

スタッフがページの「＋ イベントを追加」から入力したイベントは、Googleスプレッドシートに保存されて全員の一覧に並びます。保存先が未設定のあいだは、追加ボタンは表示されません。

### 初回セットアップ（1回だけ）

1. Googleスプレッドシートを新規作成する（名前は自由）
2. メニュー「拡張機能 → Apps Script」を開き、`gas/Code.gs` の中身を貼り付けて保存
3. 左の「プロジェクトの設定（歯車）」→「スクリプト プロパティ」に追加
   - プロパティ：`PASSCODE`　値：スタッフに伝える書き込み用パスコード
4. エディタで関数 `setup` を選んで「実行」（権限の確認が出たら許可）。見出し行と既存イベントが入る
5. 「デプロイ → 新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：自分　／　アクセスできるユーザー：全員
6. 発行された `https://script.google.com/macros/s/…/exec` のURLを `config.js` の `EVENTS_API` に入れて push

### 運用メモ

- 閲覧はだれでも可。追加・編集・削除はパスコードが必要（入力した端末に記憶される）
- パスコードを変えるときはスクリプト プロパティを書き換えるだけ（再デプロイ不要）
- `gas/Code.gs` を直したときは「デプロイを管理 → 編集 → 新バージョン」で更新（URLは変わらない）
- シートを直接編集してもよいが、1列目の `id` は消さない
